Portafolio web interactivo y de alto rendimiento diseñado para exponer mi experiencia como **Ingeniero de Software** (Mobile & Full-Stack). La interfaz combina una estética *Neo-Retro / Cyberpunk minimalista* con componentes *Glassmorphism*, priorizando la experiencia de usuario (UX) y la presentación técnica de proyectos.

🔗 **[Ver Portafolio en Vivo](https://josercalles.github.io/portafolio-jose-calles/)** *(Asegúrate de actualizar este enlace si es distinto)*

---

## ✨ Características Destacadas

*   🧱 **Arquitectura Bento Grid:** Sistema de cuadrícula asimétrica (`BentoSection`) para presentar información y proyectos de forma dinámica, moderna y altamente escaneable.
*   🎨 **Diseño Glassmorphism & Neón:** Tarjetas de proyectos (`ProjectCard`) con fondos traslúcidos, bordes reactivos y sombras de colores neón (Cyan, Púrpura, Verde, Amarillo) que responden al *hover*.
*   📱 **Responsive First:** Completamente adaptable a pantallas móviles, tablets y monitores de escritorio usando Tailwind CSS.
*   ⚡ **Rendimiento Optimizado:** Construido sobre Vite para tiempos de compilación ultrarrápidos y recarga en caliente (HMR).
*   🚀 **Despliegue Continuo:** Configurado con rutas estáticas (`base path`) para despliegue sin errores en GitHub Pages.

---

## 🛠️ Stack Tecnológico

*   **Framework / Librería:** React (JSX)
*   **Build Tool:** Vite
*   **Estilos:** Tailwind CSS (Custom themes, utility-first)
*   **Iconos:** Lucide React / Héroe Icons (Opcional)
*   **Despliegue:** GitHub Pages
